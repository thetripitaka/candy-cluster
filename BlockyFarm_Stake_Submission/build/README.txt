HOW TO RUN
1. Serve the contents of the /build folder via a local or remote web server
2. Open index.html through the served URL in a modern browser (Chrome recommended)
3. Audio will activate after the first user interaction (click/tap)

NOTE
This is a modern HTML5 module-based build and must be served over HTTP/HTTPS.
Opening index.html directly via the file system is not supported.

PLATFORM NOTES
- HTML5 web-based game
- Mobile portrait orientation only (by design)
- Desktop supported in scaled view
- Landscape mode is intentionally locked on mobile

CONTROLS
- Spin, turbo, and settings are available via on-screen UI
- Audio mute and volume controls are available in settings

BUILD NOTES
- This is a final submission build
- No debug tools or developer overlays included
- All assets are final and self-contained
- No runtime external network dependencies (all assets bundled locally)

STORE ASSETS
- Store tile, thumbnail, and screenshots are located in /store
- Screenshots reflect actual gameplay and portrait orientation
